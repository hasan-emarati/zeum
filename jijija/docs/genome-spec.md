# مشخصات ژنوم (Genome Spec) — نسخه 0.1 (پیش‌نویس)

> **یادداشت:** نسخه قبلی این سند بدون خوانده‌شدن بازنویسی شد. این متن پیش‌نویس جدید است و مسیر ریشه SD را با `tools/embed_organs.py` (که `/CREATURE/organs` می‌گوید) هماهنگ می‌کند؛ ممکن است با نسخه از دست‌رفته فرق داشته باشد.

ژنوم هر چیزی است که موجود یاد گرفته یا ساخته و روی SD ذخیره می‌شود. ساختار SD:

```
/CREATURE/
├─ identity.toml          شناسه موجود، تاریخ تولد، نسخه فرمت
├─ organs/                نسخه‌ای از شناسنامه‌های اندام‌هایی که دیده شده
├─ genome/
│  ├─ words/<name>.fs     کلمات Forth (متن)
│  ├─ index.toml          فهرست کلمات: نسخه، امتیاز، اندام‌های لازم، وضعیت
│  └─ history/            نسخه‌های قدیمی هر کلمه (برای Rollback)
├─ memory/
│  ├─ events-YYYYMMDD.log رویدادهای مهم
│  └─ stats.bin           آمار فشرده (آستانه‌های یادگرفته‌شده و ...)
└─ trash/                 جهش‌های رد‌شده (برای تحلیل، قابل پاک‌سازی)
```

## `genome/index.toml`

```toml
[[word]]
name     = "blink-slow"
file     = "words/blink-slow.fs"
version  = 3
requires = ["led"]            # اندام‌های لازم؛ اگر نباشند کلمه غیرفعال می‌ماند
score    = 0.71               # امتیاز شایستگی آخرین ارزیابی
status   = "active"           # candidate | active | retired | quarantined
parent   = "blink-slow@2"     # نسخه والد
crc32    = "a1b2c3d4"
```

## چرخه عمر یک جهش

1. **candidate**: کلمه جدید (از موجود بالاتر یا جهش داخلی) در `trash/` یا `words/` با وضعیت candidate.
2. اجرا در حالت **آزمایشی** (Watchdog فعال، شمارنده بوت-ناموفق).
3. اگر دستگاه ریست شد یا Watchdog زد → شمارنده بالا می‌رود؛ بعد از N بار → **quarantined**.
4. اگر امتیاز از والد بهتر بود → **active**؛ والد → history.
5. Rollback یعنی بازگرداندن نسخه از `history/`.

## ملاحظات

- ژنوم قابل‌انتقال بین موجودات است، فقط اگر `requires` برآورده شود.
- هر فایل کلمه با CRC32 در فهرست راستی‌آزمایی می‌شود؛ ناهمخوانی یعنی نسخه فایل مشکوک است و بارگذاری نمی‌شود.
- فاز ۰.۴ فقط ساختار را تعریف می‌کند؛ اجرای Forth در فاز ۳ و ۵ است.
