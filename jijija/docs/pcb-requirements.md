# نیازمندی‌های فریمور برای طراحی PCB (فقط پیشنهاد؛ تصمیم و طراحی با کاربر است)

این سند نمی‌گوید «چه قطعه‌ای بخر». می‌گوید فریمور لاگر برای قطعاتی که کاربر فهرست کرده چه منابعی لازم دارد و کجا تعارض هست. همه شماره‌پین‌ها از حافظه‌ام برای STM32F103C8 است و باید با دیتاشیت و برد کلونت چک شود.

## ۱. منابع لازم

| نیاز | تعداد | یادداشت |
|---|---|---|
| I2C | ۲ باس | باس ۱: DS3231 (۰x68)، MPU6050 شماره ۱ با AD0=VCC (۰x69)، ADXL345 (۰x53 با SDO=GND). باس ۲: MPU6050 شماره ۲ (۰x68). دلیل: DS3231 و MPU هر دو ۰x68 |
| SPI | ۱ | کارت SD (ماژول 74LVC125) |
| ADC | ۶ کانال | سه KY-037، LM35، نور (LDR)، باتری |
| GPIO | ۲ | دو DHT22 (هر کدام یک پین، زمان‌بندی نرم‌افزاری) |
| وقفه EXTI | ۳ + ۱ | خروجی دیجیتال سه KY-037 (رفلکس جا خوردن)؛ SQW دی‌اس‌۳۲۳۱ (۱ Hz) برای اندازه‌گیری رانش کریستال. خطوط EXTI باید همه شماره متفاوت داشته باشند |
| PWM | ۴ | LED RGB (۳ کانال) + بازر (۱ کانال) |
| ارتباط با PC | ۱ | USB CDC (دستورهای `ev`/`meta` و وضعیت) |

## ۲. تخصیص پیشنهادی (تعارض‌ها حل شده، ولی تأیید نشده)

| عملکرد | پین |
|---|---|
| ADC: گوش چپ / وسط / راست | PA0 / PA1 / PA2 |
| ADC: LM35 | PA3 |
| ADC: نور / باتری | PB0 / PB1 |
| SPI1: SD (CS، SCK، MISO، MOSI) | PA4، PA5، PA6، PA7 |
| I2C1 (SCL، SDA) | PB6، PB7 |
| I2C2 (SCL، SDA) | PB10، PB11 |
| PWM RGB (TIM1 CH1–3) | PA8، PA9، PA10 |
| PWM بازر (TIM4 CH3) | PB8 |
| DHT22 شماره ۱ / ۲ | PB12 / PB13 |
| KY-037 دیجیتال L / C / R | PB14 / PB15 / PB9 |
| DS3231 SQW | PB5 |
| USB CDC | PA11 / PA12 (ثابت) |
| SWD | PA13 / PA14 (ثابت) |

**تعارض‌هایی که حل شد:** USART3 با I2C2 (PB10/11) هم‌پین است، پس سریال روی USB CDC رفت؛ USART1 (PA9/10) با PWM رنگ هم‌پین است، پس USART1 استفاده نمی‌شود؛ TIM2 روی PA0–PA3 با ADC تداخل دارد؛ PC14/PC15 کریستال ۳۲ kHz بلواپیل است و استفاده نشده. PC13 LED روی برد است.

## ۳. نکات چیدمان که روی کیفیت داده اثر می‌گذارند

- **LM35 حداقل ۴ ولت** تغذیه می‌خواهد (از ۵V)؛ خروجی‌اش حدود ۰.۲۵ ولت در اتاق است و برای ADC ۳.۳ ولتی بی‌خطر است. یک فیلتر RC کوچک روی خروجی بگذار.
- **KY-037 را با ۳.۳ ولت** تغذیه کن تا خروجی آنالوگ از محدوده ADC بیرون نزند.
- **تغذیه آنالوگ:** VDDA/Vref را از ریل ۳.۳ با فیلتر (فریت + خازن) بده. SD هنگام نوشتن جریان ضربه‌ای می‌کشد و اگر ریل مشترک و بی‌فیلتر باشد، روی ADC نویز می‌اندازد.
- **زمین آنالوگ و دیجیتال** را در یک نقطه به هم برسان؛ مسیر سیگنال KY-037 و LM35 را از خطوط SPI و PWM دور نگه دار.
- **LED RGB دور از LDR** باشد تا روی نور اندازه‌گیری‌شده اثر نگذارد.
- **DHT22 و LM35 را از منبع گرما** (رگولاتور، بلواپیل) دور بگذار و موقعیتشان را در متادیتا ثبت کن، چون هر تغییر چیدمان یعنی داده جدید.
- **سه KY-037** را با فاصله مشخص (مثلاً ۸ تا ۱۰ سانتی‌متر) بگذار و فاصله را ثبت کن؛ برای جهت‌یابی لازم است.
- **INMP441** روی بلواپیل نمی‌رود (I2S ندارد). اگر بخواهی روی همان PCB باشد، یک ریل جدا برای یک برد I2S‌دار یا کانکتور بگذار.
- **رمز بلواپیل ۲۰ KB** است؛ بافر SD ۵۱۲ بایتی و صف رکورد کوچک کافی است، ولی Forth و مدل روی همین برد جا نمی‌شود.
